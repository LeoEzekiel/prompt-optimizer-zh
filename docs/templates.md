# 模板说明文档

## 内置模板一览

| 模板 ID | 名称 | 描述 | 版本 |
|---------|------|------|------|
| `general-optimize` | 通用优化 | 适用于大多数场景的标准模板 | 1.3.0 |
| `output-format-optimize` | 带格式优化 | 需要严格输出格式时使用 | 1.3.0 |
| `advanced-optimize` | 深度思考版 | 复杂任务，需要 LLM 深度推理 | 2.1.0 |
| `iterate` | 迭代优化 | 在已有 prompt 基础上定向改进 | 1.0.0 |
| `structured-format` | XML 标签版 | 输出 XML 格式，适合程序处理 | 1.0.3 |
| `elderly-friendly` | 适老化专用 | 专为老年人产品设计优化 | 1.0.0 |
| `ethnic-unity` | 民族团结 | 多民族内容表述规范 | 1.0.0 |

## 1. general-optimize（通用优化）

### 适用场景
- 初次优化任何 prompt
- 没有特殊格式要求
- 通用场景首选

### 输出结构
```
# Role: [角色名称]

## Profile
- language: [语言]
- description: [详细的角色描述]
- background: [角色背景]
- personality: [性格特征]
- expertise: [专业领域]
- target_audience: [目标用户群]

## Skills
1. [核心技能类别]
   - [具体技能]: [简要说明]

2. [辅助技能类别]
   - [具体技能]: [简要说明]

## Rules
1. [基本原则]：
   - [具体规则]: [详细说明]

2. [行为准则]：
   - [具体规则]: [详细说明]

3. [限制条件]：
   - [具体限制]: [详细说明]

## Workflows
- 目标: [明确目标]
- 步骤 1: [详细说明]
- 步骤 2: [详细说明]
- 预期结果: [说明]

## Initialization
作为[角色名称]，你必须遵守上述 Rules，按照 Workflows 执行任务。
```

## 2. output-format-optimize（带格式优化）

### 适用场景
- 需要严格的输出格式
- 返回 JSON、表格等结构化数据
- API 自动化处理场景

### 额外内容
在通用模板基础上增加：
```
## OutputFormat
1. [输出格式类型]：
   - format: [格式类型]
   - structure: [输出结构说明]
   - style: [风格要求]

2. [格式规范]：
   - indentation: [缩进要求]
   - sections: [分节要求]

3. [验证规则]：
   - validation: [格式验证规则]
   - error_handling: [错误处理方式]

4. [示例说明]：
   - 示例1：[具体示例内容]
   - 示例2：[具体示例内容]
```

## 3. advanced-optimize（深度思考版）

### 适用场景
- 复杂任务需要深度推理
- 任务涉及多个领域知识
- 需要生成可执行的行动计划

### 核心特点
- **共情激励**：利用"避免失业"的心理暗示提升 LLM 投入度
- **多维度分析**：从 10 个角度全面分析 prompt
- **5 条建议**：每个结构必须输出 5 条具体建议

### 输出维度
1. Role - 角色定位
2. Background - 背景分析
3. Attention - 注意力要点
4. Profile - 画像定义
5. Skills - 技能清单
6. Goals - 目标拆解
7. Constrains - 约束规则
8. OutputFormat - 输出格式
9. Workflow - 工作流程
10. Suggestions - 优化建议

## 4. iterate（迭代优化）

### 适用场景
- 已有优化后的 prompt
- 需要在特定方向上改进
- 发现某些部分不够满意

### 工作原理
```
输入:
  - 原始 prompt（已优化版）
  - 优化需求描述

处理:
  - 保持核心意图
  - 定向改进指定部分
  - 避免过度修改导致偏离原意

输出:
  - 改进版 prompt
  - 使用原有格式
```

### 示例
```
原始 prompt：[刚才生成的 prompt]
优化需求：增加语音朗读提示，标注停顿和重音位置
```

## 5. structured-format（XML 标签版）

### 适用场景
- 需要程序化处理的场景
- API 自动化工具链
- 批量 prompt 生成

### 输出格式
```xml
<optimized_prompt>
<task>任务描述</task>

<context>
原始提示词内容，保持原文不变
</context>

<instructions>
1. 第一步指令
2. 第二步指令
   - 子项一
   - 子项二
</instructions>

<output_format>
期望的输出格式描述
</output_format>
</optimized_prompt>
```

## 6. elderly-friendly（适老化专用）⭐ 新增

### 适用场景
- 老年人产品的设计
- 大字体、简单操作的产品
- 助老类应用

### 核心特点
- **认知适配**：指令简洁，避免双重否定
- **情感共鸣**：尊重老年人人生经验
- **安全红线**：不推荐自行诊断用药

### 特殊约束
```
## Rules（适老化专项）
1. 字体规范：明确要求大字体（不小于 18px）、高对比度
2. 操作简化：每步操作不超过 3 次点击
3. 反馈及时：操作后 2 秒内给出明确反馈
4. 语音辅助：关键信息支持语音朗读
```

## 7. ethnic-unity（民族团结）⭐ 新增

### 适用场景
- 涉及多民族的 content
- 民族团结宣传教育
- 文化多样性展示

### 核心原则
```
## Rules（民族相关专项）
1. 表述规范：使用官方标准民族名称（56 个民族全称）
2. 避免刻板：不将某民族与特定负面标签关联
3. 均衡呈现：各民族文化贡献均衡描述
4. 尊重差异：承认并尊重各民族的独特性
5. 历史准确：涉及民族历史事件需核实史实
```

### 禁止事项
- ❌ "少数民族往往..."（刻板印象）
- ❌ 将特定民族与贫穷、落后关联
- ❌ 忽视各民族的历史贡献
- ✅ "中国 56 个民族共同创造了灿烂文明"
